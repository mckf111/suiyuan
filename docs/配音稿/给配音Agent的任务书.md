# 任务书：为《重游随园》网页配音

## 目标

为网页《重游随园》的 94 句台词生成配音，一句一个音频文件。声音要像真人朗诵：自然、有语气，不要机器腔。

## 输入（都在项目文件夹的 `docs/配音稿/` 里）

- `使用说明.md`：各角色的声音建议、交付格式、朗读注意事项。**先读这份。**
- `1_旁白_清单.csv` … `4_访客_清单.csv`：每句一行，列为序号、文件名、朗读文本、语气提示、读音提示、场景、段落、引文。
- `*_朗读文本.txt`：与清单同序的纯文本，一句一行。
- `0_全部.csv`：全部台词按游园顺序排列，用于整体试听和校对。
- `按顺序改名.py`：把按顺序导出的音频（001、002……）批量改成清单里的文件名。

## 要做的事

1. **定声音，先试听**：给旁白、袁枚、书童各选一个声音（访客可选，不配也行）。每个角色先生成 3 句试听，交给我确认后再批量生成。建议试听句：
   - 旁白：`chaimen_l0`、`dayuan_l0`（文言）、`epi4_q`
   - 袁枚：`chaimen_l3`、`dayuan_a0_0`（文言）、`mubie_l3`
   - 书童：全部 3 句
2. **批量生成**：念的内容只能取“朗读文本”一列，一字不改；语气按“语气提示”处理。
3. **处理读音**：“读音提示”列标出的字必须读对。工具支持拼音或音素标注就用上；不支持的，改用工具自带的发音修正功能，**不要改动朗读文本**。
4. **命名与格式**：文件名用“文件名”一列（如 `chaimen_l3.mp3`）。mp3 128 kbps 以上或 wav，单声道，44.1 或 48 kHz；首尾静音各不超过 0.2 秒；响度统一到约 −16 LUFS。
5. **自检**（见下方验收标准），不合格的句子重新生成。
6. **交付**：音频全部放进项目文件夹的 `audio/voice/`，另附一份 `audio/voice/配音报告.csv`，列为：文件名、角色、时长（秒）、响度（LUFS）、是否重生成过、备注。

## 验收标准

- 文件数和清单句数一致，文件名一一对应，没有多余或缺失。
- 每个文件都能正常播放；时长在合理范围内（大约每字 0.2 到 0.4 秒），没有截断，也没有长段空白。
- 把音频转写回文字，与“朗读文本”逐句比对：不能漏字、多字或念错字，重点检查“读音提示”里的字。
- 同一角色前后音色一致，不能中途换了一个人似的。
- 各句响度差不超过 ±2 LU。

## 不要做的事

- 不改台词文字，不改文件名规则。
- 不修改 `audio/voice/` 以外的任何文件，尤其不要动网页源码（`src/`、`src2/`、`suiyuan.html`）。
- 不删除任何已有文件。需要清理的，列在报告里交给我处理。
- 用到付费服务、上传到第三方平台，或需要登录新账号之前，先问我。

## 完成后

告诉我交付的文件数、每个角色用了什么声音或工具，以及报告里有哪些需要人工复听的句子。接入网页由另一方负责，你不用处理。
