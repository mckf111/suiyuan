# 试听稿：每个角色 3 句

用来先定声音。满意了再批量生成。

## 旁白
1. **chaimen_l0**：乾隆五十年，仲春。你出北门桥西行，过红土桥，便到了小仓山下。
   语气：开场，平静舒展
2. **dayuan_l0**（文言）：入大院，四桐隅立。面东为三楹，筦龠全园。
   语气：放慢，按标点断句。读音：筦龠 guǎn yuè，隅 yú，楹 yíng
3. **epi4_q**：至此偌大金陵城，再无袁枚一砖一瓦。
   语气：全片最后一句，放慢，收住。读音：偌 ruò

## 袁枚
1. **chaimen_l3**：可算把你盼来了。门是柴门，园子却不小，你随我慢慢走。
   语气：见到老友，热络带笑
2. **dayuan_a0_0**（文言）：使吾官于此，则月一至焉；使吾居于此，则日日至焉。二者不可得兼，舍官而取园者也。
   语气：放慢，按标点断句。读音：舍 shě，焉 yān
3. **mubie_l3**（文言）：然则余之仕与不仕，与居兹园之久与不久，亦随之而已。
   语气：淡然，略带怅惘，放慢。读音：余 yú，仕 shì，兹 zī

## 书童
1. **chaimen_l2**：先生，客人到了！
   语气：朝园里喊，欢快
2. **zhujing_l2**：客人留神，竹叶上还挂着露水。
   语气：清亮、恭敬
3. **mubie_l0**：先生，天黑了，灯笼点上了。
   语气：轻声提醒

## 听的时候注意
- 袁枚像不像年近七十、温厚风趣的江南文人：不要苍老到发颤，也不要像播音员。
- 三句文言有没有念对字、断对句。
- 书童和袁枚放在一起听，两人的声音有没有明显区别。
