## 交付要求

- **格式**：mp3（128 kbps 以上）或 wav 都可以，单声道，44.1 kHz 或 48 kHz。
- **文件名**：用清单里的“文件名”一列，例如 `chaimen_l3.mp3`。一句一个文件。
- **首尾**：句首句尾各留不超过 0.2 秒静音。
- **音量**：各句响度尽量一致；工具有“响度统一”选项的话，设在 −16 LUFS 左右。
- **放哪里**：全部放进项目文件夹的 `audio/voice/`，告诉我一声，我来接进网页并打开配音开关。

## 念的时候注意

- **引文**（清单里“引文”列标“是”的句子，多为袁枚诗文或史料原句）：放慢，按标点断句。文言句后面往往紧跟一句白话解释，两句之间自然停一下。
- **读音**：多音字和生僻字都写在“读音提示”列。配音工具支持拼音标注的话（如“为[wèi]”），可以按提示加上；不支持就换个近音说法，或者在工具里单独改那一个字。
- **朗读文本已做过处理**：阿拉伯数字改成了汉字读法（如“一九二三年”），括注的年份去掉了。页面上显示的文字不受影响。
- **语气提示**只是参考，按配音员或工具的理解来就好。
